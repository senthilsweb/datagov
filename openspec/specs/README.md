# Living capability specs

One directory per capability (`cli-interface/spec.md`,
`dataset-inspection/spec.md`, …) holding the **current, verified**
requirements for that capability. The full capability list is PRD §31.

This directory starts empty by design: spec deltas are authored inside
`openspec/changes/<name>/specs/<capability>/spec.md` and merge here only
when the change is verified and archived. Nothing lands here directly.
